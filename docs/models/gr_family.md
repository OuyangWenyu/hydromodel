# GR Family (gr1a / gr2m / gr3j / gr5j / gr6j)

Besides GR4J, the project registers several other members of the GR model family:

| Model | Registered name | Parameters |
|-------|-----------------|------------|
| GR1A | `gr1a` | 1 |
| GR2M | `gr2m` | 2 |
| GR3J | `gr3j` | 3 |
| GR5J | `gr5j` | 5 |
| GR6J | `gr6j` | 6 |

All GR models follow the same NumPy/Numba function interface and are calibrated through the unified API.
